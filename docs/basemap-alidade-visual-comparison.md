# Alidade Smooth visual comparison

Decision **B**: make Alidade Smooth the default light basemap; retain OpenStreetMap in Layers. The gain is consistent in A.T.O.M overlay work, especially SINR, selected networks and area selection. Useful roads, intersections, building mass, parks and district/place labels remain. OSM remains valuable when rich POI/landmark context takes priority.

Reviewed all 15 matched pairs before the default change. Captures use real provider PNGs with bounded downloads and a temporary successful-tile cache. The same deterministic 42-Cell fixture (six selected plus 36 dense Söğütözü positions), building fixtures, RF fixtures, camera, overlay opacity and viewport apply within each pair. These are visual fixtures, not new RF accuracy or production-dataset claims. See [capture measurements](assets/basemap-alidade/evidence.json).

The basemap competes less with teal, orange, red and blue and reads as a neutral engineering canvas. No numeric UX score was used. Low-zoom OSM provides richer land-use/POI descriptions; closer Alidade views still provide usable street and building context.

SINR remains red below 0, amber 0–13, blue 13–20, teal at least 20 dB, and gray for no signal. The same colors, category boundaries, point geometry, Cell rings and opacity are used in both providers. No filter applies to scientific panes. Orange selection versus amber SINR is resolved by the existing ring/order and sample-dot shapes; this experiment does not invent a new palette.

Map key/attribution collision and horizontal overflow checks run for every capture, including 1366×768, 1512×982 and 390×844. Phone attribution is allowed to wrap, with basemap-specific key clearance. Basemap selection uses a compact radio group in the existing Layers menu.

Limitations: visual evaluation by the implementing agent; deterministic overlay fixtures rather than every real dataset condition; remote tile latency depends on provider/cache/network. Capture waits and tile counts establish load stability, not a controlled provider speed benchmark. No dark mode or alternate map engine was introduced.

Raw scientific canvas hashes are also recorded. After viewport resizing, Leaflet can redraw antialiased circle edges with tiny byte differences: the inspected 1366px case changed 63 edge pixels (0.0048% of the canvas; maximum channel delta 6). Exact geometry/marker positions, viewport, semantic CSS palette and renderer source remained unchanged. Contract tests at settled fixed viewports retain exact canvas equality.
