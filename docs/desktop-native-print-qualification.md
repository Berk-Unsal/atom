# Production Print qualification

Status: the complete configured virtual-printer flow passes both hosted X11 and native Wayland sessions. Follow-up to #156/#158/#161 and PR #203; the scoped proof below does not approve a public release.

The native-dialog workflow configures `AtomQualification`, an unshared local CUPS-PDF queue, only on its disposable Ubuntu 24.04 VM. It uses the distribution's [CUPS-PDF driver](https://packages.ubuntu.com/noble/amd64/printer-driver-cups-pdf/filelist) and [CUPS queue administration](https://www.cups.org/doc/man-lpadmin.html). No remote or personal printer is used. The installed app must enumerate the queue through real `getPrintersAsync()`, while CUPS `lpstat -d` independently confirms the actual default.

After the seven existing production chooser actions, the real Report Print button calls the existing non-silent production path. The driver observes the owned 1440×900 compositor through Ubuntu's [Mutter ScreenCast interface](https://github.com/GNOME/mutter/blob/gnome-46/data/dbus-interfaces/org.gnome.Mutter.ScreenCast.xml) and a private PipeWire session. It identifies the Print title, General tab, Printer table, Cancel/Print controls and visibly blue-selected local queue from actual pixels. OCR analyzes white-on-blue controls separately and maps their original pixel bounds back to the screen. Both the observed X11 bottom-button layout and Wayland header-button layout are supported; ambiguous/missing controls or an unselected queue fail before any input.

The driver clicks the observed control's center once through native Wayland's owned Mutter RemoteDesktop session or X11 XTest. X11 additionally requires the uniquely visible exact-PID Print window and checks the target lies inside its observed native geometry. No fixed control coordinates, Electron print method/callback or OS response is substituted. Ordinary app launch uses no forced Chromium accessibility mode; the external GTK file-chooser driver keeps its own AT-SPI scope. These compositor/input APIs are qualification tooling, not production dependencies.

Cancel must return control without creating a CUPS job or changing retained artifacts and saved PDF bytes. A subsequent real Print must complete exactly one job and produce a PDF through the local virtual printer. Its bounded first-page raster must visibly retain the Project, Simulation Run and report labels. Native Save PDF independently must preserve exact Unicode Project/Run text through extraction. Receipts, original compositor screenshots and the first-page print diagnostic are retained; temporary OCR images, generated report/PDF files and bundled data remain excluded from upload. The existing single explicit RF request, final Save, ordinary Quit, process cleanup and unchanged installed-bundle assertions remain active. Owned compositor/PipeWire/session-manager processes are cleaned up by the existing private runtime harness.
