# Production desktop qualification work record

Scope: #158, integrated production Electron host after #149–#157. This work is in progress. Accepted Electron supersedes the roadmap's original Wails/WebKit native-engine assumptions; a WebKit browser subset remains an early warning, not evidence for a supported native WebKit target. No public desktop support, redistribution or signing approval is implied.

## Measurement protocol

`npm run build --prefix desktop` stages the exact committed UI and Go executable. `npm run test:startup-budget --prefix desktop` requires a clean checkout and matching resource build identity. It records 20 paired fresh-profile launches and same-profile process relaunches, actual sidecar lifecycle timestamps from the existing redacted log, and launch-to-enabled-Run-Sector time. Filesystem/OS caches are uncontrolled: fresh profile/process is not a cold disk claim. No global cache purge is performed.

The same complete host/UI/binary is measured after 60 seconds idle with the full unchanged default pack and the canonical tiny sample pack. Every descendant host, renderer, GPU, utility and owned Go process appears in the process-tree record. Aggregate RSS sums shared pages; Linux PSS is additionally recorded when readable. Full-minus-sample is an observed whole-tree difference, not an isolated allocator measurement. Private temporary test profiles/resources are removed and owned processes must exit.

The original launch/readiness and 500 MiB aggregate RSS guidance remains an explicit comparator. A missed budget is recorded as `BUDGET_REVIEW_REQUIRED` and the command fails; this task cannot approve its own budget revision. Map/input, deterministic RF parity/timing, actual OS surfaces, the complete platform matrix and local package size are separate required measurements. Existing functional native suites retain their narrower claims.

Routine automation blocks public OSM from process startup, retains the production sandbox and never raises production RF admission limits. Test automation uses Playwright's external Electron harness; no privileged qualification endpoint is added to release code. Public default-data packaging remains subject to the [pending exact-hash review](desktop-data-redistribution-review.md).

## Actual macOS surfaces and follow-up defects

The [actual OS-surface record](assets/desktop-native-os-surfaces-macos.json) is scoped to clean `8be59eb` on macOS product/kernel 27.2/27.2.0 arm64. CUA operated native Save As, Open and Cancel panels without replacing their methods. The UTF-8 project is valid, cancellation preserves bytes/association, and Open establishes the chosen file association. The real native Save PDF chooser writes a tagged, script-free 10-page A4 PDF. One explicit Sector request supplies its report; file/report output performs no additional RF request. Normal native Quit with Recovery closes the owned app. This is not a clean-machine install or macOS 14/Intel qualification.

Print fails before an OS Print surface can open. Read-only `lpstat -p -d` confirms no configured destination or system default. Retained report bytes remain available, and Save PDF still succeeds. No printer was installed or system setting changed; actual Print-surface qualification remains open on an environment with a configured test printer.

The physical Save test exposes a first-association dirty-status defect: identical saved/recovery serialization remains marked dirty until another edit or Run. A controlled native reproduction confirms the host still has the pre-association timestamp revision while the file contains the correct shared content hash. The controller now synchronizes the latest context after association; it does not force an old captured Save clean if inputs changed during the chooser. Unit and real-native first-Save regressions cover a fresh project before any RF or Version.

The same OS exercise exposes omitted Report Run lineage even though the Version metadata explicitly names its actual draft Run and dataset/model/request identity matches. Current-report lookup now attributes only that exact current Version's explicit source Run, without changing its immutable stored record. Regeneration uses the Report definition's recorded Version, validates every requested Run, and preserves previous bytes on unavailable or incompatible sources. Missing/foreign/unknown-project/already-differently-bound Runs and live network evaluation cannot borrow a Run. Native report qualification checks the actual source card after Run → Save Version.

Finally, initial Go validation/build now retries only when an observed source edit supersedes compiler input, discards obsolete outputs, and still surfaces a genuine current-source error. The real development-loop fixture deliberately holds an editor's partial empty file until supersession is observed, then completes the write. Approved registry label corruption is also rejected without rewriting settings; legacy metadata remains unverified and unchanged. These follow-up fixes are undergoing clean-source native/CI qualification; their unit results do not replace it.
